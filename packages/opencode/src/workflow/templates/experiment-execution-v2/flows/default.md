# Experiment Execution

Work through three broad phases:

1. Understand the experiment, prepare a plan, and obtain user approval.
2. Implement and validate the plan, then obtain approval before remote execution.
3. Autonomously prepare, deploy, run, monitor, and recover the experiment.

The workflow defines approval boundaries, not a fixed implementation procedure. Within each phase, inspect the current state and use the available tools directly. Specialist subagents are optional.
